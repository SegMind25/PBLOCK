# Adult Content Blocker

A permanent, irreversible adult content blocking system built with Rust and Vue.js.

## ⚠️ WARNING

**This blocker is PERMANENT. Once activated, it CANNOT be disabled or removed easily.**

## Features

- System-level blocking via hosts file modification
- Blocks 50+ major adult content domains
- Cannot be disabled once activated
- Runs as system service (background)
- Modern Vue.js interface

## Installation

### Linux/Mac
```bash
sudo ./install.sh
```

### Windows (Run PowerShell as Administrator)
```powershell
.\install.ps1
```

## Usage

1. After installation, access http://localhost:3000
2. Set an admin password
3. Check the "I understand" checkbox
4. Click "Activate Blocker Permanently"
5. The blocker will now run forever
